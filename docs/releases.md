# Releases

Deprecated aliases remain available for one minor release, not one patch release.
See [compatibility](../CONTRIBUTING.md#compatibility) before upgrading legacy profiles.
Publication uses npm trusted publishing with provenance.
The release publish job checks build, lint, tests and generated documentation before publishing.
See the [release workflow](../.github/workflows/release-please.yml), [GitHub releases](https://github.com/knowttl/vectra-axi/releases) and [npm versions](https://www.npmjs.com/package/@knowttl/vectra-axi?activeTab=versions).
